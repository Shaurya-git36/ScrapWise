COMMON QUESTIONS

Frequently asked questions

Are the scrap rates updated live?

No. The prices shown are example values entered manually for this frontend project.

Does submitting the form book a real pickup?

No. This version shows an on-screen confirmation but does not send data to a collector.

How is the payout estimated?

JavaScript multiplies each material's entered weight by its example price per kg and adds the amounts.

Can the website work on mobile?

Yes. Bootstrap grid classes adjust the columns for different screen widths.
